# Security Policy

## Supported Status

SafePay is currently under active development. **All operations run in Test Mode only.** Live mode transactions and real money movements are built into the architecture but are deliberately switched off.

| Version / Mode | Supported |
|---|---|
| Development / Test Mode | Yes |
| Live Mode / Real Money | Disabled |

---

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability in SafePay, please report it responsibly and privately.

### How to Report

Please use **GitHub's Private Vulnerability Reporting**:
1. Navigate to the repository on GitHub: [https://github.com/SimretAbebe/SafePay](https://github.com/SimretAbebe/SafePay)
2. Click on the **Security** tab.
3. Click on **Report a vulnerability** under "Vulnerability reporting".
4. Provide a detailed summary, including reproduction steps, affected endpoints or components, and any relevant logs or proof of concept.

> **Important**: Never disclose suspected vulnerabilities, tokens, or credentials in public GitHub issues, pull requests, or forum discussions.
